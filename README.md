# Genius CRM 2.0

Профессиональная стартовая версия CRM для репетиторского центра.

## Запуск локально
npm install
npm run dev

## Netlify
Build command: npm run build
Publish directory: dist

## Environment variables
VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY

## Реализовано в v0.1
- Подключение к Supabase
- Ученики: список, поиск, добавление, удаление
- Педагоги: список, добавление
- Главная панель
- Заготовки расписания, оплат, документов
- Адаптация под телефон
